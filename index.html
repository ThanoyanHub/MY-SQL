What is MySQL?

A powerful open-source relational database management system (RDBMS)

What it does

MySQL stores data in tables (like spreadsheets), lets you retrieve/modify it with SQL, and handles millions of records reliably. Used by Facebook, Twitter, YouTube, and WordPress.

Structure: Database → Table → Row

A database holds many tables. Each table has columns (fields) and rows (records). Think: a folder full of spreadsheets.

SQL — the language

SQL (Structured Query Language) is how you talk to MySQL. It has 4 core operations: SELECT, INSERT, UPDATE, DELETE

Working with Databases

Creating, selecting, and managing databases

mysql_query.sql 
-- Create a new database
CREATE DATABASE school;

-- Use/select a database to work in
USE school;

-- List all databases
SHOW DATABASES;

-- Delete a database (careful!)
DROP DATABASE school;

-- Create only if it doesn't exist
CREATE DATABASE IF NOT EXISTS school;

Tables

Define the structure of your data

CREATE TABLE students (
  id      INT AUTO_INCREMENT PRIMARY KEY,
  name    VARCHAR(100) NOT NULL,
  email   VARCHAR(150) UNIQUE,
  age     INT,
  grade   CHAR(1),
  enrolled DATE
);
-- See table structure
DESCRIBE students;

-- Add a new column
ALTER TABLE students ADD COLUMN phone VARCHAR(20);

-- Remove a column
ALTER TABLE students DROP COLUMN phone;

-- Delete all rows but keep table
TRUNCATE TABLE students;

-- Delete the whole table
DROP TABLE students;

Data Types

Choose the right type for each column

Numbers

INT BIGINT FLOAT DECIMAL

Use DECIMAL for money. Use INT for IDs.

Text

CHAR VARCHAR TEXT

CHAR is fixed length, VARCHAR is variable.

Date & Time

DATE DATETIME TIMESTAMP

TIMESTAMP auto-updates. Format: YYYY-MM-DD

Other

BOOLEAN ENUM JSON

ENUM restricts values. JSON stores structured data.

CRUD Operations

Create, Read, Update, Delete — the core of data manipulation

-- INSERT: Add rows
INSERT INTO students (name, email, age) VALUES
  ('Alice', 'alice@mail.com', 20),
  ('Bob', 'bob@mail.com', 22);

-- UPDATE: Modify rows
UPDATE students
SET age = 21, grade = 'A'
WHERE name = 'Alice';

-- DELETE: Remove rows
DELETE FROM students
WHERE age < 18;

-- ⚠ Without WHERE, all rows are affected!

SELECT & Filtering

Retrieve exactly the data you need

SELECT name, age FROM students
WHERE age >= 18
  AND grade = 'A'
ORDER BY name ASC
LIMIT 10 OFFSET 0;

-- Pattern matching
SELECT * FROM students WHERE name LIKE 'A%';

-- Match list of values
SELECT * FROM students WHERE grade IN ('A', 'B');

-- Range
SELECT * FROM students WHERE age BETWEEN 18 AND 25;

-- Check for NULL
SELECT * FROM students WHERE email IS NULL;

JOINs

Combine data from multiple tables

INNER JOIN

Only matching rows in both tables.

LEFT JOIN

All from left + matches from right (NULL if no match).

RIGHT JOIN

All from right + matches from left.

CROSS JOIN

Every combination (cartesian product).

-- INNER JOIN example
SELECT s.name, c.course_name
FROM students s
INNER JOIN enrollments e ON s.id = e.student_id
INNER JOIN courses c ON e.course_id = c.id;

-- LEFT JOIN: include students with no courses
SELECT s.name, c.course_name
FROM students s
LEFT JOIN enrollments e ON s.id = e.student_id
LEFT JOIN courses c ON e.course_id = c.id;

Aggregate Functions

Summarise and group data

-- COUNT, SUM, AVG, MIN, MAX
SELECT
  COUNT(*) AS total,
  AVG(age) AS avg_age,
  MAX(age) AS oldest,
  MIN(age) AS youngest
FROM students;

-- GROUP BY: aggregate per group
SELECT grade, COUNT(*) AS count
FROM students
GROUP BY grade
HAVING COUNT(*) > 5 -- filter on group result
ORDER BY count DESC;

WHERE vs HAVING

WHERE filters rows before grouping. HAVING filters after grouping. Use HAVING to filter on aggregate results like COUNT or SUM.

Indexes

Speed up queries dramatically

Why indexes?

Without an index, MySQL scans every row (full table scan). With an index, it jumps directly to matching rows — like a book's index. Trade-off: faster reads, slightly slower writes.

-- Create an index
CREATE INDEX idx_name ON students(name);

-- Unique index (enforces uniqueness)
CREATE UNIQUE INDEX idx_email ON students(email);

-- Composite index (multiple columns)
CREATE INDEX idx_grade_age ON students(grade, age);

-- See indexes on a table
SHOW INDEXES FROM students;

-- Check query performance
EXPLAIN SELECT * FROM students WHERE name = 'Alice';

Constraints

Enforce data rules at the database level

CREATE TABLE orders (
  id            INT AUTO_INCREMENT PRIMARY KEY,
  student_id    INT NOT NULL,
  amount        DECIMAL(10,2) CHECK (amount > 0),
  status        ENUM('pending','paid','cancelled') DEFAULT 'pending',
  created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (student_id) REFERENCES students(id)
    ON DELETE CASCADE
);

Key Constraints

  • PRIMARY KEY Unique ID
  • FOREIGN KEY Link tables
  • UNIQUE No duplicates
  • NOT NULL Required

ON DELETE Actions

  • CASCADE Delete child
  • SET NULL Nullify FK
  • RESTRICT Block delete
  • NO ACTION Restrict

Subqueries

Queries nested inside other queries

-- Subquery in WHERE
SELECT name FROM students
WHERE age > (SELECT AVG(age) FROM students);

-- Subquery in FROM (derived table)
SELECT g.grade, g.avg_age
FROM (
  SELECT grade, AVG(age) AS avg_age
  FROM students
  GROUP BY grade
) AS g
WHERE g.avg_age > 20;

-- EXISTS: check if subquery returns rows
SELECT name FROM students s
WHERE EXISTS (
  SELECT 1 FROM enrollments e
  WHERE e.student_id = s.id
);
